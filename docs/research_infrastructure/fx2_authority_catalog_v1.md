# FX2 Central Authority Catalog v1

Work ID: `FX2-RESEARCH-EXECUTION-ENVIRONMENT-CONSOLIDATION-001`

`authority/authority_catalog.json` is the central metadata index. It records repository path, SHA-256, Git blob SHA, source commit, row count where line-based counting is possible, parent/supersession fields, Release/asset metadata, retention status, and reconstruction command.

The generator is metadata-only. It does not evaluate candidate economics or inspect protected trade values. Large authorities remain in immutable Releases or approved object storage and require byte-identical remote readback. Notion is an index only.

Mandatory retention covers raw Tick, canonical bars, signal/trade/decision-state/source-map/full-equity/chronology ledgers, authority manifests, rule and implementation hashes, final decisions, and readback receipts.
