# USDJPY R4 Governance Boundary v1

R4 is the first stage that emits a shortlist. The following boundary is fixed:

- R4 may select no more than eight H1 Entry/horizon representatives.
- Selection is based only on the preregistered common gates, equal-weight ranking and redundancy controls.
- Fewer than eight representatives is an acceptable result; no gate relaxation is permitted.
- Selected horizons remain diagnostic time exits and do not become operational Exit policies.
- R5 may compare only separately preregistered Exit-policy families and limits.
- H2, 2025, Core and MT4 remain closed.
